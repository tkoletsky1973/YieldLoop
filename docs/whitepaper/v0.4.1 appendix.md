# YieldLoop  
## Appendices — Technical, Accounting, and Governance Specifications

**Author:** Todd Koletsky  
**Date:** 2025-12-31  
**Version:** v0.4.1  

These appendices define the deterministic mechanics, accounting rules, execution constraints, and governance boundaries that implement the YieldLoop system described in the main whitepaper.

The appendices are authoritative for implementation, audit, and verification purposes.  
The main whitepaper defines guarantees and limits; these appendices define how those limits are enforced.

---

## Appendix Table of Contents

### Appendix A — System State Machine & Cycle Finality  
Defines all valid vault states, transitions, invariants, and terminal conditions.  
Establishes cycle finality, recovery behavior, and refusal logic.

### Appendix B — Cycle Settlement Math & Valuation Rules  
Defines deterministic settlement inputs, valuation methods, cost accounting, profit verification, and zero-resolution logic.

### Appendix C — Zero-Result Cycles, Dormancy, and Inactivity  
Enumerates all scenarios where cycles correctly resolve to zero and where the system may remain idle indefinitely without failure.

### Appendix D — LOOP Accounting, Supply Rules, and Floor Mechanics  
Defines LOOP as an accounting record of verified retained surplus.  
Specifies minting rules, supply invariants, accounting floor behavior, stagnation cases, and non-redemption guarantees.

### Appendix E — Time, Cycles, Cutoffs, and Authorization Windows  
Defines all time-based constraints governing authorization, execution duration, settlement timing, retries, and recovery escalation.

### Appendix F — Execution Engine & Trade Strategy Specifications  
Defines the requirements, constraints, and prohibited behaviors for all execution engines and trade strategies, including but not limited to:
- Arbitrage
- Yield farming
- Routing and indexing
- Future bounded strategies  
No strategy may operate outside these constraints.

### Appendix G — Fee Structure, Discounts, and Allocation Boundaries  
Defines:
- Platform fee structure (prospective and adjustable)
- Discount logic for whitelisted supporters and governors
- Fee allocation categories (development, operations, reserves, research)
- Governor-controlled bounty or incentive pools  
All values are configurable and non-guaranteed.

### Appendix H — Whitelisting, Access Control, and Governance Roles  
Defines non-NFT access control, including:
- Supporter whitelisting via smart contract deposit
- User-controlled wallet reassignment
- Governor designation via administrative authorization
- Role-based privileges and limitations

### Appendix I — Fiat Access, Onboarding, and Account Abstraction Boundaries  
Defines how fiat onramps, payment rails, and account abstraction may be integrated without violating non-custodial control, user ownership, or settlement integrity.

### Appendix J — Security Model, Threat Boundaries, and Emergency Powers  
Defines explicit in-scope and out-of-scope threats, administrative limitations, emergency halt powers, and upgrade boundaries.

### Appendix K — Observation, Proof, and Non-Authoritative Metrics  
Defines optional, non-authoritative observation layers for finalized outcomes, including proof generation, audit data, and research metrics.

### Appendix L — Glossary of Canonical Terms  
Defines authoritative meanings for all system terms used throughout the YieldLoop documentation.
